## Current source operations - 0.6.0

The local provider path imports validated immutable publications, retains the
last good dataset and separates successful source checks from business-data
cutoffs. Each investigation captures one provider version; tools, citations,
checkpoints and feedback retain that identity. Actual Qwen generation was
verified on one scheduled VALORANT series after preserving three failed attempts.
This is a measured example, not a broad real-data accuracy scorecard.

The separately enabled public profile displays bounded processed football and
VALORANT cards, explicit UTC windows, source delays and visible credits. The
GitHub delivery workflow uses encrypted secrets and a serialized, best-effort
hourly schedule. Ephemeral hosted ingestion does not claim preserved historical
availability or durable source CDC. Local inference remains separate from the
static public website.

## Current calendar and event directories - 0.7.0

One immutable capture couples the selected strict dataset with its nullable
source calendar. The bounded public v2 contract retains source-derived event
relationships, unresolved dates and opponents, and explicit result states.
Independent UTC date filters precede counting and pagination. The original v1
display remains readable with unavailable calendar coverage clearly marked.

Local investigation links must match both the current canonical fingerprint and
the selected match identity. Stale selections return a refresh requirement before
tools or model execution. Public delivery remains static and hourly; routine
browser checks run once, with longer repetitions available only by manual dispatch.

Next work: measure actual source-to-Spark replay, expand reviewed coverage, assess
forecast eligibility and calibration, and complete human semantic evaluation and
managed-platform acceptance. Fixture and model-double checks are separate from
native inference and deployed-source measurements.

The OpenFootball view is a separate real-data research workspace. Only explicit
numeric offsets permit UTC kickoff conversion. Completion instants,
regulation-time targets and historical pre-match availability remain unresolved,
so the research agent does not publish forecasts. Its tools, citations and trace
ledger are separate from canonical synthetic chat. Actual collection establishes
availability now; historical dates cannot establish earlier availability.
